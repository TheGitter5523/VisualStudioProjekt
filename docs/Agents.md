# Project Context

This project is an independent demonstration website for fictional student
banking transactions. Its author is **TheGitter5523**.

## Development Instructions

- Keep the Retro-Wave and hacker-style design consistent.
- Keep styling in `style.css`, separate from `index.html`.
- Preserve the bilingual English/German interface.
- Keep the CSV data fictional and unchanged unless a task explicitly requires
  a data change.
- Preserve the fixed client-side login behavior and do not add registration.

## Documentation Rule

Whenever another project file is changed, review `Readme.md` and update it in
the same task if the change affects the website, dataset, styling, structure,
usage, or any other documented project behavior. Keep the README consistent
with the current state of the project.
